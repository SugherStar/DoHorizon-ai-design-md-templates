# 温暖浅色设计规范模板

一份可复制的 `DESIGN.md` 模板，用于给设计者或代码生成工具明确视觉规则。它从“金织”项目的设计文档中提炼出配色、字体、8px 间距、组件、响应式布局与轻量动效约束，适合需要温暖、克制界面的网页项目。

这是**设计规范文档模板**，不包含可运行的网站代码。

## 文件

- [`DESIGN.template.md`](DESIGN.template.md)：可填写的设计规范；包含一套默认浅色配色和组件规则。

## 快速使用

1. 将 `DESIGN.template.md` 复制到你的项目，并重命名为 `DESIGN.md`。
2. 替换所有 `{{...}}` 字段：项目名、产品类型、目标用户、使用场景、品牌点缀和前端技术栈。若没有品牌点缀，删除相关规则。
3. 按项目需要统一调整颜色、字体、间距和组件令牌。默认值是一套示例，不要求沿用“金织”的品牌色。
4. 将完成的 `DESIGN.md` 交给团队或代码生成工具，并在开发过程中保持文档与实现一致。

可直接使用下面的提示词：

```text
请先阅读项目中的 DESIGN.md，再实现以下页面或组件：
【填写功能和内容】
使用文档中的设计令牌与组件规则；如果需求与规范冲突，先指出冲突并说明需要修改的规范条目。
```

## 模板覆盖的内容

| 部分 | 用途 |
| --- | --- |
| 项目概况 | 固定产品定位、受众、场景和风格 |
| 设计令牌 | 集中管理颜色、字体、间距、圆角、边框和阴影 |
| 组件规则 | 统一按钮、卡片、输入框和导航 |
| 布局与动效 | 约束断点、装饰范围和交互反馈 |
| 交付检查 | 检查一致性、响应式与基本可用性 |

## 使用边界

模板仅描述界面设计，不提供业务逻辑、内容策略或完整无障碍审计。项目若需要暗色主题、不同视觉风格或更多组件，应先扩充设计令牌和规则，再用于代码生成。默认字体为 Inter；中文项目应选定可用的中文回退字体。
